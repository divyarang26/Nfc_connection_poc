| Component   | Purpose                                                                   |
| ----------- | ------------------------------------------------------------------------- |
| **NFC**     | The technology for close-range wireless communication.                    |
| **NDEF**    | A simple format to store messages on NFC tags (like links, contact info). |
| **HCE**     | Allows an Android phone to act like an NFC smart card (virtual card).     |
| **ISO-DEP** | The protocol used for secure and structured data communication.           |
| **AID**     | The unique ID used to target a specific app on the card or HCE service.   |
